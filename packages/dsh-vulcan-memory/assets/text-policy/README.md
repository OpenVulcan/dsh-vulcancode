# VulcanCode text rules

The bundled rules come from VulcanCode commit `dc7c49b1a`, under `crates/vulcan-runtime-assets/resources/memory`. The DSH host uses the common PII rules and one selected region. Noise filtering uses the common and Chinese rules.

规则来自 VulcanCode 的 `dc7c49b1a` 提交。DSH 应用通用 PII 规则及用户选择的一个地区，噪声过滤使用通用和中文规则。
