# @openvulcan/dsh-decision-guard

Vulcan Decision 自动审批插件，属于 [dsh-vulcancode](https://github.com/OpenVulcan/dsh-vulcancode) 套件，随套件
安装，不单独安装：

```sh
dsh plugin add @openvulcan/dsh-vulcancode
```

The Vulcan Decision auto approval plugin, part of the
[dsh-vulcancode](https://github.com/OpenVulcan/dsh-vulcancode) suite. It is installed with the suite, not on
its own.
